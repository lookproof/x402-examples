# Lookproof x402 endpoints

Base URL: `https://api.lookproof.dev`. Every operation below answers `402 Payment Required` (x402 v2) until paid; the `PAYMENT-REQUIRED` header has the exact price. No account and no API key needed. Responses are JSON.

| Network | CAIP-2 id | Asset | Scheme |
|---|---|---|---|
| Base | `eip155:8453` | USDC `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913` | `exact` |

Payments are settled only when the check returns a result. A `503` (`check_failed`, `deadline_exceeded`, `busy`) is not charged. Signatures must come from an ordinary wallet (EOA); smart-contract wallets are not supported. Limits: 60 requests per minute and 5000 per day per client IP, and at most 2 concurrent paid requests per IP.

Free: `/openapi.json`, `/healthz`, and `POST /v1/mail/check/bulk/retry` (re-runs the failed items of a paid bulk request with its `retry_token`). `GET /v1/usage` is for API-key customers and has no x402 price.

Generated by `scripts/gen_endpoints.py` from Lookproof's OpenAPI document (`https://api.lookproof.dev/openapi.json`). Example responses are Lookproof's illustrative examples for `example.com`, trimmed (`...`); they are not live data.
